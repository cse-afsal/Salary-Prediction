# 💰 Salary Prediction Using Machine Learning

## 📌 Project Overview

This project predicts employee salaries based on factors such as years of experience using Machine Learning. The model learns patterns from historical salary data and estimates salaries for new employees.

## 🎯 Objective

To build a Machine Learning model that can predict salary based on employee information, helping organizations and individuals make data-driven decisions.

---

## 📊 Dataset

The dataset contains:

| Feature | Description |
|----------|-------------|
| YearsExperience | Number of years of work experience |
| Salary | Employee salary (Target Variable) |

Example:

| YearsExperience | Salary |
|---------------|---------|
| 1.1 | 39343 |
| 1.3 | 46205 |
| 3.2 | 54445 |
| 5.0 | 66029 |
| 10.5 | 121872 |
